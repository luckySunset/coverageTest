# coverage-vue3

基于 Vue 3.3.4 + Vite 4.3.9 创建的工程，Node 版本 18.13.0。

## 安装依赖

```bash
npm install
```

## 开发

```bash
npm run dev
```

## 构建

```bash
npm run build
```

## 预览构建产物

```bash
npm run preview
```

## 目录结构

```text
coverage/
├── index.html
├── package.json
├── vite.config.js
├── public/
│   └── favicon.svg
└── src/
    ├── main.js
    ├── App.vue
    └── components/
        └── HelloWorld.vue
```
